# Железо и дела

Личное приложение: привычки и задачи по дням, цели на неделю, тренировки FullBody A/B/C с рабочими весами и таймером отдыха, прогресс, замеры тела и КБЖУ.

## Как пользоваться

- Открой сайт на телефоне в Safari → «Поделиться» → «На экран Домой». Приложение работает и без интернета.
- Все данные хранятся только в браузере на этом устройстве, в репозиторий они не попадают.
- Раз в неделю делай резервную копию: «Ещё» → «Настройки» → «Скачать резервную копию». Восстановить её можно там же.
- Перенести данные из версии на claude.ai: там скачай копию, здесь нажми «Восстановить из копии».
- ИИ-тренер и синхронизация между устройствами работают только в версии на claude.ai.

## Как обновить

1. Правки вносятся в `zhelezo.html`.
2. `python build.py` собирает папку `docs/`.
3. Сделай коммит и отправь: GitHub Pages раздаёт `docs/` из ветки `main`.
